📊 Prometheus Observability Metric: auth_errors_total

Exposed at http://localhost:8080/actuator/prometheus and automatically scraped every 5s by Prometheus.

PromQL: Error Rate by Business Code

sum by (code) (rate(auth_errors_total[5m]))

Generates time-series line chart in Grafana displaying error frequency per custom code.

PromQL: Top 5 Failing Error Codes

topk(5, sum by (code) (auth_errors_total))

Used for Grafana Pie Chart / Donut Chart of error distributions.

PromQL: Alert Rule for 500 Spikes

sum(rate(auth_errors_total{code="AUTH-000500"}[1m])) > 5

Fires alert to Slack/PagerDuty whenever internal server errors spike.

Loki Query: Filter Logs by Error Code

{app="iam-service"} |= "AUTH-000104"

Instantly finds all log lines matching this error code across all pods/instances.
